💡 *My Project:*
ElderSync — Patient-Centred Elderly Care & Collaborative Medication Adherence Platform

🔍 *Problem Statement:*
Elderly Care & Medication Management Platform

🛠️ *What I Built:*
Most medication apps stop at passive phone alarms that get swiped away, leaving families unaware when an elderly relative misses critical medication. ElderSync reimagines this with a patient-first, collaborative model where elderly independence meets proactive family safety:

• Patient Sovereignty: The elderly patient owns their profile, confirms doses with large >=56px touch controls, generates single-use Care Circle passcodes, and controls granular sharing permissions.
• Deterministic Escalation Engine: When a dose is unconfirmed past the configurable grace window (default 3 min for demo), ElderSync server-side triggers real caregiver escalation alerts with idempotent outbox deduplication.
• Closed-Loop Caregiver Collaboration: Caregivers receive real-time alerts and can record follow-up notes (e.g., "Called Papa, confirmed taken"), preventing duplicate panicked calls from multiple family members.
• Cryptographic Care Circle: Single-use, 15-minute expiring SHA-256 hashed 6-digit passcodes with rate limiting and constant-time verification.
• Senior-First Accessibility: Designed to WCAG AAA standards with >=56px touch targets, 18px-22px font scalers, high-contrast mode, and Web Audio API confirmation chimes.
• Adherence Insights & Appointments: Computes real 7-day adherence trends, time-of-day routine disruption windows from recorded dose logs, and manages doctor visits with proactive reminders.

💻 *Tech Stack:*
• Frontend: React 18, TypeScript, Tailwind CSS, Vite, Lucide Icons, Web Audio API
• Backend: Node.js, Express, Zod, Rate Limiting, Idempotent Outbox Engine
• Deployment & Infra: Google Cloud Run (Multi-Stage Alpine Docker Container), Cloud Scheduler
• AI Engineering & Testing: Google Antigravity (10-Phase Iterative Spec Architecture documented in PROMPT_LOG.md), Vitest + Supertest (10 Automated Test Suites, 100% Pass Rate)
